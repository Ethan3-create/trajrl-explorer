GCC
GCC是Linux上的常用编译工具，支持多种
编程语言。
gcc main.c -o main 编译单个文件
gcc main.c -o main && ./main 编译并运行
分阶段
gcc -E main.c -o main.i 预处理
gcc -S main.i -o main.s 生成汇编文件
cc1 main.i -o main.s
gcc -c main.s -o main.o 生成目标文件
as main.s -o main.o
gcc main.o -o main 链接生成可执行文件
ld main.o -o main -lc -dynamic-linker
/lib64/ld-linux-x86-64.so.2 ...
是否允许调试（借助GDB）
gcc -g main.c -o main

============================== PAGE 9 ==============================
反汇编工具-objdump
常见的汇编代码分为AT&T 风格（目的操作数在右）和Intel 风格（目的操作数
在左）两种
给定一个二进制文件，我们可以使用反编译工具得到他们的汇
编代码，如objdump 。
默认情况下objdump -d myhelloworld 生成AT&T风格的
汇编
objdump 提供--intel 选项，支持生成Intel风格的汇编
objdump -d <binary-file>
-d :表示--disassemble 反汇编.text 段
-D :表示--disassemble-all 反汇编所有代码段
OBJDUMP的一般使用
# 使用objdump的--disassemble=sym 指定符号
attacklab$ objdump --disassemble=main ctarget

GDB调试
调试二进制程序，支持多种编程语言
程序可调试的条件
gcc -g 允许在目标文件中加入调试信息
包括变量、函数的数据类型
源代码行号与可执行代码地址的关联
strip
对编译好的程序，剥离符号信息
调试会变得很困难
查看代码
设置断点
调试
$ gdb myhello
# 设置参数，需要在程序运行之前
(gdb) set args 参数1 参数2 ... 
(gdb) show args # 查看设置的命令行参数
# run==r
(gdb)run # 运行，直到第一个断点位置
(gdb)start #在main函数前设置断点，并运行
# list==l
(gdb)list # 查看文件代码，从第一行开始显示
(gdb)list 行号 # 从指定行号显示一定的上下文代码，默认是显示10行
(gdb)list myfunction
# break==b 
(gdb)break myfunction #根据函数名设置断点
(gdb)break 5 # 行号
# delete==d 删除断点
(gdb)d 1 # 删除第一个断点
(gdb)d 1-5 # 删除第1到第5个断点
# continue==c
(gdb)c # 从当前位置继续执行，直到下一个断点
# step==s
(gdb)s # 单步调试，进入函数体内部
# next==n
(gdb)n # 单步调试，但不进入内部
(gdb)finish # 跳出函数内部
(gdb)until # 跳出循环体

打印变量
查看信息
# print==p 打印变量的值
(gdb)p 变量名
# 整数，可指定输出格式
# /x 十六进制、/d 十进制、/u 无符号十进制
# /t 二进制、/f 浮点数、/c 字符
(gdb)p/fmt 变量名 # fmt表示整数格式，如p/x
(gdb)ptype 变量名 # 打印变量类型
# info==i 查看状态/信息
# registers==r
(gdb)info breakpoint/break/b #查看断点信息
(gdb)info registers # 查看寄存器信息
(gdb)info frame # 查看栈帧
(gdb)info args # 查看参数
(gdb)info locals # 查看局部变量
# disas 反汇编
(gdb)disas myfunctionname

# b 一个字节、h 两个字节（半字）

$ mkdir ics

$ mkdir lab0
$ cd lab0
# 进入 ics/lab0 文件夹
$ vim hello.c
# 创建hello.c源文件，复制/输入代码
$ gcc -O0 -m32 -g hello.c -o a   
# -O0 不进行编译优化，-m32 IA-32指令，
# -g 带调试信息，搭配后续的GDB调试
# 或者增加 –no -pie –fno -pic 选项
$ objdump -S a>a.txt      
# 反汇编，-S 保留C语句，> 保存到文件 
# 用编辑器打开 a.txt 
# 根据 C 语言读懂汇编代码，认识指令
$ gdb a
# 启动 GDB 调试工具，进入 a 的 GDB 调试环境
(gdb) break main
# 在 main 函数入口处设置断点
(gdb) break a.c:3
# 源程序 a.c 的第 3 行处设置断点
(gdb) run  # 启动运行程序
(gdb) si  # (或s) 执行一条指令（语句）
# 查看所有定点寄存器内容
(gdb) i r 
# 或者，查看给定的寄存器内容   
(gdb) i r esp ebp # 或者（gdb) i r eax eflags    
# 重复执行以下步骤，观察栈中数据变化
(gdb) x/yxb $esp    # 按字节显示当前栈帧内
# y=(ebp)-(esp)+4    # 当前栈帧的字节单元数
(gdb) x/zxw $esp    # 按4字节显示当前栈帧内容 
# z=((ebp)-(esp)+4)/4    # 当前栈帧的4字节单元数
# 退出调试 
(gdb)quit
