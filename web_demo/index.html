📖 系统概述

本演示系统基于 Porto 城市出租车轨迹数据集（10,000 条样本），展示 TrajRL 论文的核心方法论与实验效果。

TrajRL 是一种自监督轨迹表示学习框架，通过多尺度时空特征探索学习通用轨迹嵌入。系统演示了以下核心模块：

  • 轨迹检索 — 基于 KNN 的相似轨迹搜索，对应论文 §V-C3 "Most Similar Trajectory Search"
  • 出行时间估计 — 距离-时长线性回归基线，对应论文 §V-C2 "Travel Time Estimation"
  • 双视图对比增强 — 路段偏移 + 时间扰动，对应论文 §IV-A、§IV-E2 "Trajectory Augmentation + Contrastive Learning"
  • 多尺度编码可视化 — Patch 分块 + InPatch/CrossPatch 层次，对应论文 §IV-D "Multi-Scale Trajectory Encoder"
  • Embedding 空间投影 — PCA 降维展示轨迹分布，对应论文 §V-D 表示质量分析

💡 论文方法说明

路段偏移（Road Segment Shifting）：随机替换部分路段为其 1-hop 或 2-hop 邻居（本系统退化为 GPS 点微小偏移模拟）。

时间扰动（Temporal Shifting）：对时间戳做 -5% ~ +5% 的随机扰动。

对比学习信号：两个增强视图构成正样本对，不同轨迹的视图构成负样本对，通过 InfoNCE 损失拉近正样本、拉远负样本。

💡 论文方法说明

Level 1: Patch Partition
将轨迹按窗口 ω 切分为不重叠的 patch
N = ⌈n / ω⌉
→
Level 2: InPatch Encoder (GRU)
捕获 patch 内路段的相关性
H_i = GRU(X_i, H_0)
→
Level 3: CrossPatch Encoder (Transformer)
捕获 patch 之间的相关性
Z = MultiHeadTransformer(E)
→
Level 4: Scale Fusion
多尺度融合得到最终表示
z = Σ β^(l) · z^(l)

💡 论文方法说明

TrajRL 通过多尺度时空编码器将轨迹映射到 d=256 维的表示空间（本系统使用 48 维简化特征）。良好的表示应使相似轨迹在嵌入空间中距离相近。

PCA 降维保留了轨迹间的主要方差结构，可用于观察：1) 轨迹是否形成有意义的聚类；2) 距离/时长与嵌入分布的关联。
